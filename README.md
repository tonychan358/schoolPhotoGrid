# 學生相片電子格仔表系統

單一 HTML 檔的離線工具：上傳全校學生名單（Excel）＋相片資料夾，即時生成可列印的 A4 學生相片格仔表（每頁 4 欄 × 5 列，共 20 人），並自動列出缺失相片的學生名單。

## 私隱與安全

- 所有處理（Excel 解析、相片縮圖、A4 排版）**完全在瀏覽器本機執行**，學生名單與相片**不會上傳到任何伺服器**，亦不會離開你的電腦。
- 本倉庫只包含程式碼，**不含任何學生資料或相片**。

## 使用方法

**雙擊 `index.html`**（毋須本地伺服器；所有處理都在瀏覽器內完成，相片與名單不會離開電腦）。

1. **載入 Excel 名單**：檔案須包含 `S1`–`S6` 分頁，資料位於 **D–G 欄**（D=班別、E=班號、F=英文姓名、G=中文姓名），首行可為標題。
2. **載入相片主資料夾**：選擇資料夾（會遞迴讀取），檔名格式為 **`班別-班號.jpg`**（例：`1A-01.jpg`）。班號會自動補零配對。
3. **輸入學年**：預設 `2026-2027`，格式 `xxxx-xxxx`（格式不符會標紅但仍照顯示）。改動即時反映在所有頁面。
4. **（可選）調整相片解析度**：預設「標準 400px」已足夠 300dpi 列印，如需更清晰可揀「高 600px」。
5. **選擇班別 → 列印 / 匯出 PDF**：可揀單一班別或「🌟 全校」（逐班分頁）。列印對話框請設定 **A4 直度、邊界「無」／預設、勾選「背景圖形」**。

## 相片壓縮與檔案大小

格仔內的相片實際只印約 **21 × 28mm**，即使 300dpi 亦只需約 250 × 330px。系統會在載入相片時自動把每張縮圖再轉 JPEG（品質 0.82），**大幅減細匯出 PDF 的體積，並令列印速度快很多**。

實測（20 人一頁，來源相片 1200 × 1600px、每張約 161KB）：

| 設定 | 每張相片 | 匯出 PDF | 相對原圖 |
|---|---|---|---|
| 原圖（不壓縮） | 161 KB | 3295 KB | 100% |
| 高 600px | 28 KB | 641 KB | 19% |
| **標準 400px（預設）** | **16 KB** | **397 KB** | **12%** |
| 細 280px | 10 KB | 278 KB | 8% |

壓縮後每張約 10–28KB 是**固定**的，與來源相片大小無關；若學校原相是 2–5MB 一張（常見），減幅會遠大於上表——例如全校 800 人由約 2.4GB 降至約 13MB。

「原圖」選項保留給特殊需要，但全校匯出時 PDF 可達數百 MB 且列印極慢，一般不建議。

## 頁首（版式 B — 緊湊橫排）

每頁頂部一條 band，收窄高度以留最多空間給相片：

```
[校徽 15mm]      香港道教聯合會圓玄學院第三中學        1A 班學生相片表
                        2026-2027                        (P.1 / 2)
─────────────────────────────────────────────────────────────────
```

- **校徽**已轉 base64 內嵌於 `index.html`（256px、128 色，約 20KB），不依賴外部圖檔，整份 HTML 複製走仍然有校徽。
- 單頁班別不會顯示 `(P.x / y)`，但頁首高度不變（由校徽決定），逐班列印不會跳位。
- 校名寫死在 `SCHOOL_NAME` 常數；換校只需改該行與 `SCHOOL_LOGO`。

## 版面規格

| 項目 | 值 |
|---|---|
| 紙張 | A4 直度 210 × 297mm，`@page margin: 0` |
| 每頁人數 | 20（4 欄 × 5 列） |
| 紙張留白 | 上下 12mm、左右 10mm |
| 格仔高度 | 自動平分標題以下的剩餘空間（不寫死） |
| 相片 | `object-fit: contain`，比例不變形 |

版面採 **flex column + `minmax(0, 1fr)` grid**：標題佔實際高度，格仔表填滿剩餘空間，因此無論字體或標題高度如何變化，內容永遠剛好等於 297mm，不會溢出被切走。螢幕預覽與列印結果一致（WYSIWYG）。

## 已知限制

- **需要網絡**：Tailwind CSS 與 SheetJS 由 CDN 載入，離線環境下介面與 Excel 解析會失效。若需完全離線，須把兩個 library 內嵌入檔案。
- 缺相片的學生會顯示灰色人像佔位圖，格子底色標紅，並在頁面上方「缺失相片報告」列出。
